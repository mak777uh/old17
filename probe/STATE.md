## Архитектура (упрощена 25.11 ~21:50 local по просьбе пользователя)

Банки облачных пульсов удалены (11 задач планировщика), mirror.sh и gh auth НЕ нужны, WSL-команды не нужны. Цикл теперь такой:

1. `main` запускает `python3 tools/probe_bridge.py --serve`.
2. Пользователь пишет агенту probe любое слово в чат Вибе.
3. Агент делает всё сам: читает новые срезы/ack, формулирует вопросы в `outbox\`, обновляет state, заливает бэкап состояния в GitHub (mak777uh/old17, папка probe/) — коннектор из десктоп-сессии умеет писать.

GitHub остаётся только бэкапом и историей; облачные пульсы не используются (облако не умеет писать в GitHub). mirror.sh/notify.sh лежат в каталоге про запас, запускать их не требуется.
